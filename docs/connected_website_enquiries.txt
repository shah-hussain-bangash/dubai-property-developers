Step 645 - Connected website, Admin operations and agent enquiries

Website homepage community/path cards, collaboration CTA and Current opportunities
cards now open a contextual /enquire form. No login is required. Name, interest,
message, valid contact details and explicit permission about that enquiry are required.
A private expiring form ticket and idempotent receipt prevent accidental double-save.
This acknowledgement saves locally; it does not email or message the visitor.
Member account history includes only submissions made while authenticated as that
member. Matching an email address never grants access to anonymous enquiries.

ADMIN: /overview uses actual saved portal records: enquiries, approved agents,
properties, client briefs and planner counts. /enquiries is the shared intake inbox.
Only Admin assigns approved agents. Assigned agents see only their own enquiries,
review the source and permission, then create one owned client brief atomically.
The Client Desk, matching, shortlist and viewing/follow-up planner remain connected.
Agent revocation removes access immediately. Concurrent/stale edits fail safely.
Opted-out, closed and spam enquiries cannot be converted to clients.

INTEGRATIONS: /integrations prepares create-only source bridges for EspoCRM, Gmail,
n8n and WhatsApp Business. Keys are shown once, stored as digests, excluded from
Admin read responses, and can be disabled or rotated. They cannot read records.
The source and connection name come from the authenticated bridge, not submitted
source fields. Stable eventId retries return the original reference without duplicates.
Downloaded n8n starter is inactive, has one HTTP Request node and no trigger or
credentials. Add authorised source trigger, mapping and Header Auth credentials.
There is no inbox sync, CRM sync, alert delivery, calling or outbound sending yet.
WhatsApp is available for later configuration with your own platform account.

Confirmed CRM base URL: https://crm.example.com/

it is not part of the organisation CRM address. No CRM account was accessed.
Gmail mailbox selection happens privately in the future authorised OAuth workflow.
No mailbox address, password, provider credential or bridge key is bundled in JS.
An n8n URL was not supplied. Source bridges do not install or activate n8n.

EspoCRM webhook payloads are arrays, not this bridge payload format. Use a verified
adapter to validate the Signature header, split events, map approved fields and
supply a stable eventId (include event identity/version for updates). Direct native
EspoCRM/Meta webhook posts are not supported by this generic bridge endpoint.
A cloud CRM cannot reach this computer through localhost. A secured reachable
workflow endpoint and account authorisation are required before enabling cloud events.
Do not expose the local development dashboard or port8000 as a shortcut.
