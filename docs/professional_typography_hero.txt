STEP 640 — PROFESSIONAL TYPOGRAPHY AND DUBAI WATERFRONT HERO

The local website now pairs Cormorant Garamond display headings with Manrope
navigation, body copy, cards and forms. Heading weights, tracking and sizes are
coordinated across the public homepage, opportunities, member account, sign-in
and sign-up pages. Shared dashboard text uses the locally bundled Manrope font.
Heavy uppercase hero copy becomes title case, with the same brand message:
Invest. Build. Grow together.

Fonts are downloaded unmodified from the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/manrope
https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
Both original SIL Open Font License files accompany the local TTF files in
apps/dashboard/public/fonts. CSS @font-face uses font-display:swap and system
fallbacks. Page views and builds do not request a third-party font service.

A new locally bundled 1942x809 WebP panorama is used in the homepage hero and
the sign-in artwork. The original skyline, villa and marina assets are preserved.
The image is a photographic-style AI illustration, not a live property listing.
The original generated PNG remains unchanged; the website uses a WebP copy.

Image generated using the built-in image tool with this prompt:
Create a premium photorealistic architectural editorial hero photograph for
Dubai Property Developers, ultra-wide panoramic landscape composition about
2.4:1, ideally 2400x1000. Recognizable Downtown Dubai waterfront with the complete
slender Burj Khalifa and believable surrounding modern residential towers, seen
from across calm water in the early blue hour just after sunset. Beautiful
natural soft peach and muted pink sky fading into pale blue, warm apartment and
promenade lights reflecting on dark turquoise water, elegant foreground palm
trees only at far right edge. Understated luxury property magazine photography,
crisp detailed architecture, realistic scale and subtle natural colour grading,
no excessive saturated orange, no fantasy skyscrapers, no people. Place landmark
and strongest architecture in right 60 percent, leave left 40 percent quiet
darker skyline and sky for website text overlay. Keep the Burj Khalifa spire
completely inside the frame with sky margin. This is a photographic-style
illustrative image, not a listing. No text, no logos, no watermarks, no collage.

No authentication, member-storage, research, provider or database logic changes.
The installer backs up existing changed sources and preserves all 33 review
holds. Refresh reuses the existing owner configuration in memory and rebuilds
only the dashboard, retaining owner/member storage in its named volume.
No password or API-key entry is requested. No contacts, registrations, messages,
calls or paid searches are created by the refresh acceptance checks.

Validation: existing frontend regression suite and strict TypeScript; six offline
dashboard-only refresh simulations; HTTP checks for pages, both font files, hero
bytes and signed-out protections; actual browser inspection of the local preview.
The production Docker image is built by step640_apply.ps1 on the user's machine.
Screenshots show the available desktop viewport. Responsive CSS is included;
mobile screenshot automation is not available in the attached browser controls.
