LOCAL PROSPECT RESEARCH: POSTGRESQL STORAGE (STEP 623)

Open http://localhost:3000/prospect-research after the launcher completes.
Records and target settings now save through the local API into PostgreSQL.
The versioned extension table prospect_research_workspaces_v1 stores one bounded
workspace per active organization. It is provisioned explicitly by this delivery;
it is outside the existing Alembic migration history. API requests never create
schema. Existing lead/workflow demo stores remain memory-backed.

Setup uses the API container's existing DATABASE_URL without displaying it.
It adds the dedicated table. If the known demo-org organization does not exist,
setup creates that empty organization only, without users, roles or credentials.
Inactive organizations or missing custom organizations are refused. No existing
workspace is replaced. Database/Redis containers and volumes are not recreated.

The API and dashboard restart to load the change. Earlier in-memory fictional
lead/scenario records reset; browser prospect records remain unchanged.

If browser records exist, choose Copy browser workspace to PostgreSQL explicitly.
The operation skips duplicate emails, phones, name/company pairs and record IDs.
Existing database audience settings are retained once its revision is nonzero.
The browser copy is retained; do not assume it is removed after import.
Exports contain contact details and must be kept private.

A revision counter rejects outdated browser saves. Reload after a save failure or
conflict. There is no automatic retry or fallback to browser storage. A failed
network response can occur after a successful commit: reload to establish the
last saved state. Keep regular PostgreSQL backups; the Docker volume is persistence,
not a backup. This development console remains for local trusted use, not public
exposure. Review status does not grant any contact permission.

No automatic research, email validation, PDF generation, messaging, calls or meeting
booking is activated. The daily target remains a planning field. No paid API used.
